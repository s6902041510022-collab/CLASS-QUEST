# ADR-0005: Minimal visual design system

## Status

Accepted

## Context

เว็บต้องดูเป็นเกมที่สนุก ไม่ใช่ห้องเรียนที่น่าเบื่อ แต่ก็ต้องอ่านง่าย

## Decision

ใช้สไตล์ Minimal + Clean + Cute + Premium + Bright

## Consequences

- ไม่มี Dark Theme
- ไม่มี Cyberpunk/Horror
- White space เยอะ
- Animation ไม่เยอะเกินไป
- สีสดใส เป็นมิตร
- ใช้ Emoji และ Mascot สัตว์น่ารัก
