# ADR-0014: Editable Content

## Status

Accepted

## Context

ผู้ใช้ต้องการแก้ไขข้อมูลได้ทุกส่วน

## Decision

ระบบต้องออกแบบให้แก้ไขข้อมูลได้ทุกส่วน

## Consequences

- ครูสามารถแก้ไขเกมได้
- ครูสามารถแก้ไข Mission ได้
- ครูสามารถแก้ไข Boss ได้
- ครูสามารถแก้ไขผู้เล่นได้
- มี UI สำหรับแก้ไขที่ง่าย
