# ADR-0007: Socket.io for Real-time Communication

## Status

Accepted

## Context

ต้องการ Real-time สำหรับ Live Game Control ที่ง่ายที่สุด

## Decision

ใช้ Socket.io สำหรับ Real-time Communication

## Consequences

- ง่ายต่อการใช้งาน
- มีตัวอย่างเยอะ
- รองรับ Fallback อัตโนมัติ
- ทำงานร่วมกับ Next.js ได้
