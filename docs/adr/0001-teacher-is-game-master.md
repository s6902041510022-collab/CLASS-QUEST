# ADR-001: Teacher is Game Master

## Status

Accepted

## Context

ครูต้องควบคุมเกมทั้งหมดในห้องเรียน ทั้งการสร้าง เริ่ม หยุด และดูผล

## Decision

ครู = Game Master ที่มีอำนาจเต็มในการควบคุมเกม

## Consequences

- ครูสามารถสร้าง Mission ได้
- ครูสามารถควบคุมเกมได้แบบ Real-time
- ครูเห็นผลทั้งหมดทันที
- ครูต้องมี PIN เพื่อเข้าสู่ระบบ
