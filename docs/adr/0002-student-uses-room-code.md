# ADR-002: Student uses Room Code / QR instead of mandatory account creation

## Status

Accepted

## Context

นักเรียนไม่ควรต้องผ่านขั้นตอนสมัครสมาชิกที่ยุ่งยากสำหรับการเล่นในห้องเรียน

## Decision

นักเรียนเข้าร่วมด้วย Room Code หรือ QR Code โดยไม่ต้องสมัครสมาชิก

## Consequences

- นักเรียนเข้าร่วมได้ทันที
- ไม่ต้องจำรหัสผ่าน
- ครูควบคุมผู้เล่นผ่าน Room Code
- ข้อมูลผู้เล่นไม่ถูกเก็บถาวร
