# ADR-0010: MVP Scope

## Status

Accepted

## Context

ต้องการสร้าง MVP ที่เล่นได้จริง ไม่ใช่ระบบที่ซับซ้อนเกินไป

## Decision

MVP ประกอบด้วย:

### Teacher
- Dashboard
- Create Game
- Create Mission (Quiz)
- Publish Game
- Room Code + QR Code
- Start Game
- Live Control

### Student
- Join Room
- Lobby
- Mission (Quiz)
- Answer
- XP
- Progress
- Boss (Simple)
- Victory
- Results

## Consequences

- เล่นได้จริงตั้งแต่วันแรก
- ง่ายต่อการทดสอบ
- เพิ่ม Feature ใหม่ได้ทีหลัง
- ไม่เสียเวลากับ Feature ที่ไม่จำเป็น
